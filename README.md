# Lakshaya Computer Institute Website

A responsive website for **Lakshaya Computer Institute**, a computer training center located in New Delhi, India. The institute offers professional courses in web design, digital marketing, graphic design, video editing, e-accounting, and Management Information Systems (MIS).

## 🌟 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Course Showcase** - 6 comprehensive courses with detailed module breakdowns
- **Bootstrap 5** - Modern, mobile-first CSS framework
- **FontAwesome Icons** - Beautiful iconography throughout
- **Image Galleries** - Infrastructure, student projects, and placement partners
- **Student Testimonials** - Reviews from successful alumni
- **Contact Form & Map** - Google Maps integration with contact details
- **Smooth Scrolling** - Enhanced UX with CSS scroll-behavior

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with extensive media queries
- **Bootstrap 5.3.8** - Responsive grid, components, and utilities
- **FontAwesome 7.2.0** - Icon library
- **Vanilla JavaScript** - Bootstrap's bundle for interactive components (carousel, navbar)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or server required - pure static files

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/codewithprince20/Responsive-LCI.git
   ```
2. Open `Index.html` in your browser

Or simply double-click `Index.html` to view it directly.

## 📱 Responsive Breakpoints

- **Large screens** (≤1200px)
- **Tablets/Small laptops** (≤992px)
- **Mobiles landscape** (≤768px)
- **Small mobiles** (≤576px)
- **Very small phones** (≤480px)
